## 🚌 About the Project

This project is a modern web application designed with user experience in mind, integrating KSRTC services/information. Hosted on Firebase, it leverages a fast, client-rendered architecture to deliver dynamic content efficiently. The app is also configured as a Progressive Web App (PWA) to ensure accessibility across multiple devices.

## ✨ Features

- **PWA Support:** Installable on supported devices for a native-like app experience.
